## Full description

LearnAIoffline is a complete, offline course for developers who want to build real generative-AI applications. It teaches the modern AI engineering stack step by step, from Python and FastAPI to RAG, agents and evaluation, and comes with 52,800 multiple-choice practice questions (3,300 for every topic), each with a hint, sample code and a full explanation.

WHAT YOU WILL LEARN (16 TOPICS, 140 LESSONS)
• Python for AI engineers: typing, async, generators, Pydantic and the standard library
• FastAPI: routing, validation, dependencies, streaming (SSE), testing and deployment
• LangChain: models, prompts, LCEL, tools, structured output, create_agent and middleware
• LangGraph: state graphs, reducers, conditional edges, persistence, interrupts and multi-agent patterns
• Langfuse: tracing, observations, prompt management, datasets, experiments and evaluations
• LlamaIndex: documents, nodes, indexes, query engines, retrievers and Workflows
• Vector RAG: chunking, embeddings, vector databases, similarity search and reranking
• Graph RAG: knowledge graphs, entity extraction, Cypher, community summaries and GraphRAG
• Hybrid RAG: BM25 + dense retrieval, Reciprocal Rank Fusion, weighting and rerankers
• RAG architectures with examples: Advanced and Modular RAG, query transformation, routing, parent-document, sentence-window, RAPTOR, contextual retrieval, CRAG, Self-RAG, Adaptive RAG, Agentic RAG and Multimodal RAG
• Agentic AI with different frameworks: CrewAI, LangGraph, OpenAI Agents SDK, Google ADK, Microsoft Agent Framework / AutoGen, smolagents, tools and MCP
• Text embedding models: how they are trained, MTEB, Matryoshka embeddings, quantization and choosing a model
• LLM models: transformers, tokenization, sampling, context windows, reasoning models, fine-tuning and serving
• RAGAS: faithfulness, answer relevancy, context precision and recall, test sets and experiments
• The wider AI frameworks landscape: Haystack, DSPy, Semantic Kernel, Pydantic AI, vLLM, Ollama and more
• Model Context Protocol (MCP): hosts, clients and servers, tools, resources, prompts, sampling, elicitation, stdio and Streamable HTTP transports, building servers in Python, OAuth and security

LEARN STEP BY STEP
• A full table of contents for every topic, with a section index inside each lesson
• Jump to any topic, lesson or section at any time; nothing is locked
• Clear explanations with syntax-highlighted, copyable code examples
• Key-concept glossary with flashcards for every topic

PRACTICE THAT TEACHES
• 3,300 multiple-choice questions per topic: concepts, code reading, "what does this print?", API behaviour, calculations, matching and ordering
• Code-output and calculation questions were checked by actually running the code
• Every question has a hint with sample code, a detailed explanation and a link back to the lesson
• Practice modes: continue in order, random sets, by lesson, review mistakes, unanswered only, bookmarked, or start from any question number
• Browse the full question bank with filters

TRACK YOUR PROGRESS
• Progress for every topic and lesson: lessons completed, questions answered, accuracy
• Daily history: see exactly what you studied and practised on each day
• Study streaks, study time and a 4-week activity view
• Bookmarks for lessons and questions

PRIVATE AND OFFLINE
• Works fully offline: no account, no ads, no tracking
• No internet connection needed and no permission prompts; your progress stays on your device
• Light and dark themes, optional dynamic colours and adjustable code text size

Whether you are preparing for an AI engineer interview, moving from software engineering into AI, or want a structured way to learn LangChain, LangGraph, LlamaIndex and RAG, LearnAIoffline gives you the theory, the code and the practice in one place.
