# Topic visual language

Use 24 dp rounded, single-weight outline pictograms on 36–40 dp tonal tiles. Place each icon in its named family’s primaryContainer/onPrimaryContainer pair. Colour identifies a family, and the pictogram plus visible name identifies an individual topic.
