## Source audit
The Android project targets API 36, min 26, Kotlin 2.2.20 and Compose BOM 2025.10.01. The bundled topics.json lists **15 topics, 131 lessons, 1,009 glossary entries and 49,500 questions**. MCP is absent from that index. The brief specifies **16, 140, 1,116 and 52,800**. Store copy and marketing art use the intended release numbers. Verify that the packaged build adds 9 lessons, 107 glossary entries and 3,300 questions before using them publicly. Screenshot activity, dates and answer history are illustrative.

The manifest requests no internet permission. The current Android backup rules include progress.db and preferences in cloud backup and device transfer. Confirm the intended backup behavior before promising that progress never leaves a phone. The draft store listing says progress is saved locally. Optional billing would require a separate product decision and connectivity when purchasing or restoring.

## Install the token set
Copy the Kotlin files in compose into app/src/main/java/com/aiengineer/academy/ui/theme/, replacing the original Theme.kt. The compatibility entry point AcademyTheme and the ExtraColors, LocalExtraColors, CodeTextStyle and isAppInDarkTheme APIs preserve current call sites. Use LearnAIofflineTheme in MainActivity when wiring the new preferences. Preserve existing numeric theme_mode values (0 system, 1 light, 2 dark) and dynamic_color. Store accent, AMOLED and code-theme selections in the existing preference repository. Prefer Forest for new users. For an upgraded user, retain the previous Violet look by migrating its accent preference if desired. Expose identical DayNightSwitch controls on Home and Settings. A tap in Follow system writes the opposite explicit mode. Re-selecting Follow system resumes OS tracking. The drawing interpolates sun rays into a crescent over 220 ms with cubic easing (0.2, 0, 0, 1). Android animation duration scale controls motion. Announce Dark mode, on/off, once via the switch semantics.
 
Dynamic colour overlays app chrome only on API 31+. On older devices use the selected accent and hide or explain the unavailable setting. Keep topic tiles, quiz feedback and syntax on their own tested foreground/container pairs. AMOLED affects the dark canvas and lowest surface while cards retain visible boundaries. When using system colours, test the actual wallpaper-resolved roles on device. Contrast.csv covers 482 intended static role, syntax, and feedback combinations. Use outline for interactive boundaries, outlineVariant for decorative separators. Preserve selected/error labels and icons. Test rendered states including disabled controls, oversized text and system contrast separately.

Typography defaults to the on-device sans-serif and monospace families for immediate offline use. For the final brand build, bundle Roboto and IBM Plex Mono with their licences in res/font. Pass the bundled UI family to LearnTypography and set CodeTextStyle.fontFamily through copy for the bundled mono family. Defaults: prose 17/27 sp, code 14/22 sp. Apply reader text-size and line-height preferences in sp, retaining Android font scale. Keep long code horizontally scrollable. Suggested presets: prose 15/17/19/22 sp; code 12/14/16/18 sp; leading 1.4/1.6/1.8. Mockups use installed sans/mono fallbacks.
