@ Dynamic typing | 1
D: Names are not bound to a fixed type; the same name can later refer to an object of a different type.
T: In Python, types belong to objects, not to variable names.
F: Once a variable holds an int, assigning a string to it raises a TypeError.
C: x = 10\nx = "ten"   # allowed: x now refers to a str

@ Strong typing | 1
D: The interpreter refuses to silently combine incompatible types, raising an error instead of guessing.
T: "5" + 5 raises a TypeError in Python.
F: Python silently converts "5" + 5 into the integer 10.
C: "5" + 5   # TypeError: can only concatenate str (not "int") to str

@ Floor division (//) | 1
D: Division that rounds the result down toward negative infinity.
T: -7 // 2 evaluates to -4 because floor division rounds toward negative infinity.
F: -7 // 2 evaluates to -3 because floor division truncates toward zero.
C: 7 // 2   # 3\n-7 // 2  # -4

@ True division (/) | 1
D: Division operator that always returns a float in Python 3, even for evenly divisible integers.
T: 6 / 3 returns 2.0, a float.
F: 6 / 3 returns the integer 2.
C: 6 / 3   # 2.0

@ Banker's rounding | 1
D: Rounding halves to the nearest even number, as done by the built-in round().
T: round(2.5) returns 2 and round(3.5) returns 4.
F: round(2.5) returns 3 because round() always rounds halves up.
C: round(2.5), round(3.5)   # (2, 4)

@ math.isclose | 1
D: Compares floats within a tolerance to avoid problems caused by binary floating-point error.
U: You need to check whether 0.1 + 0.2 equals 0.3 reliably.
T: 0.1 + 0.2 == 0.3 is False in Python because of floating-point representation error.
F: 0.1 + 0.2 == 0.3 is True because Python uses exact decimal arithmetic for floats.
C: import math\nmath.isclose(0.1 + 0.2, 0.3)   # True

@ Slicing | 1
D: Extracting a sub-sequence with [start:stop:step], where the stop index is excluded.
T: In s[a:b], the element at index b is not included.
F: In s[a:b], both index a and index b are included.
C: s = "LangGraph"\ns[4:]    # 'Graph'\ns[::-1]  # reversed
B: s = "LangGraph"\nprint(s[____])  # prints 'Graph' ;; 4: ;; 5: ;; :4 ;; 4:-1

@ f-string | 1
D: A string literal prefixed with f that evaluates expressions inside braces at runtime.
T: f"{3.14159:.2f}" produces '3.14'.
F: f-strings are evaluated once when the module is imported, not when the line runs.
C: name, n = "RAG", 3\nf"{name} x{n} = {n*2:.1f}"   # 'RAG x3 = 6.0'

@ Truthiness | 1
D: The rule that empty containers, zero, empty strings and None evaluate as False in a boolean context.
T: bool([]) is False and bool([0]) is True.
F: bool("False") is False because the string spells False.
C: if not []:\n    print("empty list is falsy")

@ is vs == | 1
D: One operator compares object identity while the other compares values.
T: Two separate lists [1] and [1] are equal (==) but not identical (is).
F: a is b is always True when a == b is True.
C: a = [1]; b = [1]\na == b, a is b   # (True, False)

@ bool subclass of int | 1
D: True and False are integers 1 and 0, so they can be summed and used in arithmetic.
T: True + True evaluates to 2.
F: True + True raises a TypeError because booleans are not numbers.
C: sum([True, False, True])   # 2

T: A for loop's else block is skipped if the loop exits through break.
F: A for loop's else block runs only when the loop body raised an exception.

@ match statement | 2

@ Keyword-only parameter | 2

T: In def f(a, *, b): ..., calling f(1, 2) raises a TypeError.
F: Parameters after a bare * can be passed positionally.

@ Positional-only parameter | 2

@ Mutable default argument | 2

@ LEGB rule | 2

@ nonlocal | 2
