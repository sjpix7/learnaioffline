@ LlamaIndex | 1
D: A Python framework for connecting LLMs to your data through ingestion, indexing, retrieval, agents and event-driven workflows.
T: LlamaIndex specializes in data ingestion, indexing and retrieval for LLM apps.
F: LlamaIndex is a model-serving engine like vLLM.
C: from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

@ llama_index.core | 1
D: The core package containing LlamaIndex's base abstractions such as indexes, retrievers, query engines and Settings.
T: Integrations are installed as separate llama-index-* packages on top of llama-index-core.
F: llama_index.core contains every vector database client.
C: pip install llama-index-core llama-index-llms-anthropic

@ response_mode compact | 5

@ Hit rate | 9
